## **주제: 경기도 내 사교육 시설 입지 위치 및 특성**


### 주제 선정 이유
우리나라는 사교육을 받는 학생의 비율이 많다고 알려져 있다. 경기도에서는 어떤 과목의 학원이 위치하고 있고, 어떤 입지 특성을 갖는지 알아보고자 하여 다음과 같은 조사를 진행하였다.

### 조사 및 분석 방법
공공 데이터 포털에서 찾은 경기도 학원 목록 데이터를 바탕으로 사교육 시설의 유형, 지역별 입지 등을 분석하여 Python을 통해 시각화하였다.

### 분석 과정
Python 3.6.2와 matplotlib 라이브러리를 사용하여 그래프를 구조화했다. 학원 현황을 담은 `.csv` 파일을 다운받아 UTF-8로 재인코딩하고, 누락된 부분을 찾아 복원했다. 해당 파일을 파이썬에서 읽어들이고, 리스트 표현식을 활용해 데이터를 분리했다.  
학원 이름에서 과목을 추출해 과목 별로 학원 수를 세어 막대그래프로 나타냈다. 또한 학원이 위치한 지역을 떼어내 지역 별로 학원 수를 센 뒤 가로형 막대그래프로 나타냈다. 마지막으로 위도, 경도를 소수 둘째 자리까지 반올림한 후 튜플로 구성했다. 튜플 리스트의 값을 서로 비교하여 겹치는 지역끼리 같은 점에 나타내어 선점도 그래프로 표현하였다. 명확한 이해를 위해 경기도 지도를 배경으로 시각화하였다.

### 분석 결과 및 결론
경기도 화성시에 가장 많은 학원이 위치하며, 지역별 학생 수에 비례하여 학원들이 입지한 것을 알 수 있다. 대체로 수학, 영어 과목과 관련된 학원의 수가 압도적으로 많으며, 사회 관련 학원은 상대적으로 적음을 알 수 있다.
